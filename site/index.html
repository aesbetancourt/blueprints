Specs, notes, and diagrams in a folder you own.

Blueprints is a desktop app for thinking through software. Every document is a plain file in a vault folder, and git is built in. There is no account, no cloud, and no database.

    A vault is just a folder.

    Point Blueprints at any directory. It shows the files as a tree and opens each one in the right editor. Markdown opens in a rich editor, .typ files compile to typeset pages as you type, .mermaid files open with a live preview, and .excalidraw files open as a canvas.

    Nothing is hidden in a database. Your editor, grep, and coding agents can read and change the same files. A file watcher shows their edits in the app at once.

    Tags live in each note's frontmatter, so they move with the file. Commits go to the repo you already have.

    One window for the whole spec.

    A spec is rarely only text. Blueprints keeps the prose, the diagrams, and the config next to each other in tabs.

    Write

    Rich and Raw modes
    Edit Markdown visually, or switch to the source with one click.
    Typst
    Typeset documents with a live page preview, inline errors, and PDF export. The compiler is built in, so you install nothing.
    Slash commands
    Type / at the start of a line to add headings, tasks, tables, or code.
    Templates
    Start from 36 templates, such as Feature Spec, ADR, RFC, Runbook, and Dev Log.
    Variables
    Type {{ to insert {{today}}, {{now}}, or your own values.

    Draw and model

    Mermaid
    Edit diagrams as code with a live preview, or embed them in a note.
    Excalidraw
    Sketch on a whiteboard canvas that saves as a file in the vault.
    JSON, YAML, XML, and CSV
    Edit data files in a code editor next to an interactive graph view.
    Images
    Zoom, pan, and rotate images, or show them inline with ![alt](path).

    Connect

    Wiki links
    Type [[ to link a file. Click the link to open it.
    Backlinks and outgoing links
    See which documents refer to the current one, and what it refers to.
    Tags
    Group documents across folders with frontmatter tags and colored badges.
    Search
    Search file names or contents across the vault, with regex.

    Keep

    Git panel
    Stage, commit, see diffs, and read the log without leaving the app.
    Auto-save
    Files save when you switch tabs or leave the app. ⌘S saves at once.
    Inbox and scratch pad
    Capture a quick note to inbox/, or jot in a scratch pad.
    Token estimate
    The status bar shows about how many tokens a document uses in an AI agent.

    How I use it.

    Blueprints is a personal tool. This is the loop it was built for, from a loose idea to a spec a coding agent can act on.

    1. Open a vault One folder per project or area. Each folder is its own git repo.
    2. Capture the idea Press ⌘⇧N. A timestamped note goes to inbox/.
    3. Start a real document Press ⌘N and pick a template, such as Feature Spec or ADR.
    4. Link it up Connect related docs with [[name]]. Check the backlinks.
    5. Draw what words cannot Put a Mermaid or Excalidraw file next to the spec it explains.
    6. Tag across folders Add tags in the Tags panel, then filter the vault by tag.
    7. Commit the thinking Open the Git panel with ⌘⇧G when a decision is done.
    8. Hand it to an agent Give the finished spec to a coding agent. The token count shows its size.

    Build it yourself.

    There are no releases yet. You build the app from source with pnpm and Rust. The main target is macOS. Other platforms are not tested.

    • Node.js 26 LTS (24 LTS also works), and pnpm 9 or later
    • A stable Rust toolchain
    • The Tauri system dependencies for your OS 
    $ git clone https://github.com/aesbetancourt/blueprints
$ cd blueprints && pnpm install

# Run with hot reload
$ pnpm tauri dev

# Build the app bundle
$ pnpm tauri build
# macOS: src-tauri/target/release/bundle/macos/Blueprints.app
